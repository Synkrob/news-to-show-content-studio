# News to Show — Content Studio

This GitHub Pages preview is the tablet-first prototype for the News to Show workflow: research, selected stories, scripts, hybrid video finishing, and publishing drafts.

Open the page on a phone or tablet to test the navigation and workflow. The current version is a static prototype. Use the `Scheduled research feed` box to paste the completed `AiX Practical AI News` task response and import one dated canonical feed; selections and archive items are migrated rather than cleared, sources are retained, and opinion ideas remain separate. The handoff is manual because ChatGPT scheduled tasks do not expose a supported direct connection to a GitHub Pages page. Cloud research, caption processing, storage, and publishing connections remain separate future work.
